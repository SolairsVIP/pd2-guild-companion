# 界面截图

这些图片来自本项目实际运行的界面，用于仓库 README 和版本介绍。

| 文件 | 内容 |
| --- | --- |
| `guild-home.jpg` | 公会大厅与队伍、装备数量概览 |
| `party-lobby.jpg` | 拼车队伍、模式、报名人数和出发时间 |
| `gear-import.jpg` | 粘贴单件装备 JSON 并解析到分享表单 |
| `character-equipment.jpg` | 角色穿戴槽位与固定属性面板 |
| `mercenary-equipment.jpg` | 佣兵装备切换 |
| `contribution-badges.jpg` | 贡献次数、已领取徽章与后续等级 |
| `gear-card.png` | 由网页本地生成的 PNG 属性卡 |

拍摄环境为 `npm run demo` 启动的独立内存演示站。公会、昵称、房间和物品均为虚构示例；角色配装通过人工构造的 JSON 导入，属性数值仅用于展示界面，不是实际角色数据或配装建议。

为展示徽章状态，截图环境额外完成了五次虚构交付并领取两档徽章。默认演示启动数据不包含这些额外交付和角色快照，真实数据库也没有写入它们。

JPEG 为界面实拍截图；PNG 为装备卡生成结果。游戏名称、装备名称及界面中展示的第三方图片权利归各自权利人。
